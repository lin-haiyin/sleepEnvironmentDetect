# 安全说明

[English](SECURITY.md) | [简体中文](SECURITY.zh-CN.md)

## 公开仓库边界

本仓库禁止包含生产 Wi-Fi 名称和密码、Broker 地址、设备专用 Token、证书、私钥、局域网 IP、串口日志、生成的 `sdkconfig`、构建目录或私有部署历史。

`main/secrets.h` 已被 Git 忽略。请从 `main/secrets.h.example` 创建本地文件，真实值只保存在本机；一旦误提交凭据，应先轮换凭据再继续开发。

## 部署建议

- 使用启用证书校验的 `mqtts://`。
- 每台设备使用独立账号和 ACL。
- 将设备权限限制在自身 `<device-id>/...` 主题命名空间。
- 禁止匿名 Broker 访问，并通过防火墙保护网络端口。
- 灯带电源独立供电但必须共地；不要将硬件控制接口直接暴露到公网。

## 报告方式

不要在 Issue、PR、截图或日志中公开疑似敏感信息。仓库支持时，使用 GitHub 私密安全报告联系维护者。
